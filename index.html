비교 시 주의

CFD는 공간 분포를 계산하고, lumped model은 물체 내부 온도가 균일하다고 가정합니다. 동일 위치 또는 동일한 공간 평균을 기준으로 비교해야 합니다.

측정 T10을 CFD의 고정 표면온도 경계조건으로 사용한 case에서는 T10 일치를 검증 결과로 사용하지 않습니다. 이 경우 센서 위치 공기 온도, 속도, 표면 열유속을 중심으로 비교합니다.
데이터 연결 방식
연구실 계산 자원에서 대표 조건을 미리 계산한 뒤, 온도·속도 단면은 해상도를 낮추고 압축하여 표시합니다. 대류·복사 총열전달량은 원본 표면 결과에서 먼저 계산해 case metadata로 함께 저장합니다.

실험장치 도식

교안의 장치 내부 구조를 학습용 SVG로 단순화했습니다. 실제 장치의 정확한 치수와 비례를 나타내는 도면은 아닙니다.

실험 A

  • T10은 실린더 표면 온도, T8은 관 내부 공기 온도로 사용합니다.
  • 실린더 직경 0.01 m, 가열 길이 0.07 m, 복사율 0.95, view factor 1을 사용합니다.
  • 자연대류는 McAdams 또는 Morgan 모델을 선택합니다.

실험 B

  • T6은 작은 회색체 0.5 mm, T7은 작은 흑체 0.5 mm, T8은 큰 흑체 3 mm로 표시합니다.
  • 강제대류 상관식과 비선형 복사 열수지를 사용합니다.
  • T6 복사율, 공기 물성, view factor는 수정 가능한 예시값이며 전선 전도는 포함하지 않았습니다.

Lumped-parameter 시간응답

실험 A는 실린더·히터를 하나의 평균 온도 노드로, 실험 B는 각 열전쌍 비드를 하나의 평균 온도 노드로 계산합니다. 유효 열용량, 추가 열손실, 센서 재료 물성은 실제 시간 기록으로 보정해야 합니다.

유동장과 CFD 후처리

현재 색 분포와 수치는 UI 구성을 확인하기 위한 합성 예시입니다. 실제 버전에서는 대표 조건의 CFD를 연구실 자원에서 미리 계산하고, 웹에는 축소·압축한 단면 데이터와 원본 표면에서 적분한 Qconv, Qrad를 함께 배포합니다.

  • 실험 B 자연대류 5·11·17 V와 강제대류 0.2·0.4·0.8·1.6 m/s를 모두 case로 포함합니다.
  • 복사가 solver에 직접 결합되지 않은 경우 결과 배지를 ‘CFD 온도장 + 복사 후처리’로 표시합니다.
  • CFD와 lumped model은 동일 물리량, 동일 위치 또는 동일 공간 평균을 기준으로 비교합니다.
